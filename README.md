# Vault Sync

Obsidian plugin that syncs one personal vault with its own Vault Sync server over Tailscale
(Mac, Windows and iOS). The server lives in a private repo; this repo exists so the plugin can be
installed on iOS with [BRAT](https://github.com/TfTHacker/obsidian42-brat). After the first install
the vault keeps the plugin itself up to date.

Not a general-purpose plugin: it only works with that server.
